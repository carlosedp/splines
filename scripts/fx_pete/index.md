pEte is a no-frills beat repeater as I often use it on the octatrack. it’s basically two lines of code, that allows to lock the current input in an endless loop. it makes most sense to use it in the insert slot and set to 100% wet, but feel free to experiment. there are only two parameters. it’s fun to map those to a midi controller.
